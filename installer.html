Installer sur la Recalbox

Téléchargez un seul fichier et double-cliquez dessus : il se connecte à la Recalbox et copie tout à votre place.

Fichier recalbox-rfid-installation.cmd — il s'ouvre d'un double-clic.
Que va-t-il se passer ?
  1. Le fichier apparaît dans votre dossier « Téléchargements ».
  2. Double-cliquez dessus. Si Windows affiche un avertissement, cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
  3. Une fenêtre noire s'ouvre, travaille toute seule, puis affiche « Terminé ». Vous pouvez la fermer.
  4. Redémarrez la Recalbox : l'installation se termine au démarrage (elle peut redémarrer une seconde fois pour activer le lecteur).

Si votre mot de passe root est personnalisé, ouvrez le fichier avec le Bloc-notes et remplacez la ligne set PASS=recalboxroot.

Autre méthode : copier depuis ce navigateur (Edge ou Chrome)

Pratique si le fichier .cmd est bloqué par votre antivirus : le navigateur écrit directement sur le partage de la Recalbox.

Relier cette page à la Recalbox

        

          L'adresse est presque toujours recalbox.local. Le jeton est un
          mot de passe unique, écrit par la Recalbox.
        

      

    

    

      
      
      
    

    

      
      
      
      
    

    

      Où trouver le jeton ?
      

        Le plus simple : relancez le fichier
        recalbox-rfid-installation.cmd téléchargé à l'étape 1. Il lit le
        jeton, le copie dans votre presse-papiers et rouvre cette page déjà connectée.
      

      

        Sinon, dans l'Explorateur Windows, collez cette adresse dans la barre du haut
        (Ctrl+V puis Entrée) :
        \\RECALBOX\share\system\rfid — le fichier
        token.txt s'y trouve. Ouvrez-le, copiez tout son contenu et
        collez-le dans le champ « Jeton de sécurité ».
      

      

        À savoir : \\RECALBOX tout seul ne s'ouvre pas sous Windows
        (« Windows ne peut pas accéder à \\RECALBOX ») — c'est normal, il faut toujours
        le \share. Si le nom pose problème, utilisez l'adresse IP.
      

      

        Astuce : laissez le champ vide et cliquez sur « Se connecter » — la page
        demandera une seule fois le dossier du partage et lira le jeton toute seule
        (Edge ou Chrome, partage monté en lecteur).

Associer un badge à un jeu

          

            Dans Recalbox, mettez un jeu en surbrillance. Appuyez une seconde sur le
            bouton du boîtier, puis posez le badge sur le lecteur. C'est mémorisé
            pour toujours.
