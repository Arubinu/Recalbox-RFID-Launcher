Un badge, un jeu.

Posez un badge sur le lecteur : le jeu démarre sur votre Recalbox. Cette page vous guide pas à pas, sans rien installer sur l'ordinateur.

Il vous faut une Recalbox 9 ou plus récente, un lecteur RC522, un bouton poussoir et des badges 13,56 MHz.

Installation

Quatre étapes, environ cinq minutes.

Branchez le lecteur et le bouton

Recalbox éteinte et débranchée, reliez le lecteur et le bouton au Raspberry Pi comme sur le schéma.

Uniquement sur le 3,3 V (broche 1)Le 5 V abîme le lecteur pour toujours. Aucune résistance n'est nécessaire pour le bouton.
Déjà branché ? Passez simplement à la suite.

Copiez le programme sur la Recalbox

Recalbox allumée et reliée au même réseau que cet ordinateur.

  1. Cliquez sur « Choisir le dossier de la Recalbox ». La page copie l'adresse de la Recalbox pour vous.
  2. Dans la fenêtre qui s'ouvre, cliquez dans la barre du haut, faites Ctrl+V puis Entrée. L'adresse collée est celle-ci :
    \\RECALBOX\share
  3. Cliquez sur « Sélectionner le dossier », puis acceptez la modification des fichiers. La page copie alors tout ce qu'il faut, en quelques secondes. Elle retient ce dossier : la prochaine fois, aucune fenêtre ne s'ouvrira.
Ce navigateur ne sait pas copier de fichiers.Ouvrez cette page avec Microsoft Edge ou Google Chrome, ou utilisez l'installateur Windows ci-dessous.
  1. Ouvrez l'Explorateur de fichiers et allez dans \\RECALBOX\share.
  2. Copiez-y le dossier recalbox-rfid(celui qui contient install.sh).
  3. Copiez recalbox-rfid\bootstrap\recalbox-rfid-agent(permanent).py3 dans userscripts.
  4. Recalbox 10 : copiez aussi recalbox-rfid\bootstrap\manual dans userscripts.
Ça ne marche pas ? Utiliser l'installateur Windows
Windows propose de « Diagnostiquer » ? Votre connexion est sans doute en réseau « Public », qui cache les appareils du réseau. Passez-la en « Privé » : Paramètres › Réseau et Internet › Wi-Fi ou Ethernet › votre réseau › Type de profil réseau › Privé. Sinon, utilisez l'adresse IP de la Recalbox (START › Réglages réseau), par exemple \\192.168.1.20\share.

Si Windows ne trouve toujours pas \\RECALBOX\share ou demande un mot de passe, ce petit programme se charge de la connexion et de la copie.

  1. Téléchargez l'installateur.
  2. Double-cliquez sur le fichier téléchargé. Si Windows affiche « Windows a protégé votre PC », cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
  3. Quand la fenêtre noire affiche « Terminé », revenez ici et passez à l'étape 3.

Lancez l'installation sur la Recalbox

Quelle version de Recalbox utilisez-vous ?

  1. Avec la manette, appuyez sur START.
  2. Ouvrez les réglages avancés, puis les scripts utilisateur. START Réglages avancés Scripts utilisateur
  3. Choisissez « Install-RFID-reader », puis lancez-le. L'installation démarre aussitôt, sans redémarrer.
  1. Redémarrez la Recalbox. START Quitter Redémarrer
  2. L'installation se fait toute seule pendant le démarrage.
La Recalbox peut redémarrer une fois toute seule.C'est normal : c'est ce qui active le lecteur de badges. Laissez cette page ouverte.
En attente de la Recalbox…La page passera seule à l'étape suivante.
Toujours rien ? Vérifiez que la Recalbox affiche son menu, qu'elle est sur le même réseau, et essayez son adresse IP (menu START › Réglages réseau).
Adresse de la Recalbox : recalbox.local

              Comment associer un badge à un jeu ?
      
              Sur la Recalbox, placez-vous sur le jeu dans la liste (sans le lancer). Ici, cliquez sur « Associer un badge à ce jeu », puis posez le badge sur le lecteur. Deux bips confirment.
              
    
              Je pose le badge mais rien ne se passe.
      
              Ouvrez l'onglet Matériel : tout doit être au vert. Le test du lecteur indique si le badge est bien lu. Les badges 125 kHz ne fonctionnent pas : il faut des badges 13,56 MHz.
              
    
              Pourquoi appuyer sur le bouton du boîtier pour se connecter ?
      
              C'est la sécurité : seule une personne devant la Recalbox peut autoriser un ordinateur. L'autorisation dure jusqu'au prochain redémarrage de la Recalbox.
              
    
              La page ne trouve pas ma Recalbox.
      
              Vérifiez qu'elle est allumée et sur le même réseau. Essayez son adresse IP à la place de « recalbox.local » (START › Réglages réseau). Le diagnostic Windows, dans « Se connecter » › Options avancées, vérifie tout le reste.
              
    
              Windows propose de « Diagnostiquer » quand j'ouvre \\RECALBOX.
      
              Votre connexion est en réseau « Public » : Windows y cache les autres appareils. Paramètres › Réseau et Internet › Wi-Fi ou Ethernet › votre réseau › Type de profil réseau › Privé. Vous pouvez aussi taper l'adresse IP de la Recalbox, par exemple \\192.168.1.20\share.

              Les boutons de l'en-tête suivent ceux de votre ordinateur. Un clic fixe votre choix ; un appui long revient au réglage de l'ordinateur.
