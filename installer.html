1. Installer sur la Recalbox

Un seul fichier : double-clic, aucune fenêtre à remplir.
Comment faire ?
  1. Cliquez sur le bouton : un fichier recalbox-rfid-installation.cmd est téléchargé.
  2. Double-cliquez dessus (« Informations complémentaires » → « Exécuter quand même » si Windows prévient). Il se connecte au partage, copie les fichiers et le script de démarrage.
  3. Redémarrez Recalbox : l'installation se fait toute seule au démarrage (et Recalbox redémarre une fois de plus pour le SPI).
  4. Relancez le même fichier : il ouvre l'interface de gestion avec le jeton déjà rempli (copié dans le presse-papiers).

Le fichier tente root / recalboxroot, puis l'accès invité. Si votre mot de passe root est personnalisé, ouvrez le fichier avec le Bloc-notes et remplacez la ligne set PASS=recalboxroot.

Méthode alternative : choisir le dossier (Edge/Chrome)

      Où trouver le jeton ?
      

        Sur le partage réseau de la Recalbox :
        \\RECALBOX\share\system\rfid\token.txt. Si le champ est vide,
        « Connecter » demande une seule fois le dossier du partage et lit le jeton
        tout seul (Edge/Chrome). Sinon, ouvrez le fichier avec le Bloc-notes et
        collez son contenu (ou « Charger token.txt… »). Il est créé au premier
        démarrage de l'agent.
